# COMPONENT SPEC
## AppShell
Sidebar 220px desktop; drawer tablet/mobile; sem overflow.
## Sidebar
Logo 36–40px; branding duas linhas; ícones 18–20px; active surface discreta + accent esmeralda; perfil/logout no rodapé.
## PageHeader
Título/subtítulo + período + Atualizar compactos.
## StatCard
Surface dark comum. `label | icon` / `value` / `caption`. Produção verde, setores azul, funcionários laranja, peças roxo. Sem gráficos decorativos falsos.
## ProductionTrendChart
Linha esmeralda 2–2.5px, markers pequenos, gradient fill, grid sutil, tooltip dark, labels reais se disponíveis; Dia/Semana/Mês compacto.
## SectorProductionPanel
Nome + quantidade + percentual + barra. Cores consistentes com donut.
## RankingPanel
`01 CÓDIGO ... QUANTIDADE` + barra. Top 5 real. Sem texto redundante truncado.
## SummaryPanel
Dias com produção, média diária, maior e menor produção; somente derivação real.
## RecentProductionPanel
Com registros: tabela compacta. Sem registros: empty state compacto; NÃO tabela vazia gigante.
## DistributionPanel
Donut maior, total central, legenda organizada; cores iguais aos setores.
## Estados/A11y
Loading/skeleton/success/empty/error; foco visível; teclado; aria-label; contraste; reduced-motion.
